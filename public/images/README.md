# Demo imagery

`stella.jpg` is an AI-generated fictional adult creator portrait created for this project, not a real creator endorsement. The three locked tiles reuse cropped/blurred versions of this demo asset. These are preview placeholders, not secured content. Actual VIP media must live in private Supabase Storage and use short-lived signed URLs issued after server-side entitlement checks. Never ship paid media in `public/`.

`demo-musician.webp` and `demo-dj.webp` are AI-generated fictional adult portraits for the explicitly labeled musician and DJ example pages. They do not represent real ReplyPass creators or endorsements. Generated with the built-in image generation tool from prompts for editorial portraits of a singer-songwriter in a rehearsal studio and a DJ in a music studio, respectively.

`mimi-feature.webp` is a compressed copy of the first public photo on Mimi_Kiki’s ReplyPass profile, used with the creator’s promotional permission. The homepage reads current public offer prices from her profile; this file is only a fallback portrait if that lookup is unavailable.
